# Laravel Search Syntax Parser

Laravel Search Syntax Parser turns validated search queries into Eloquent filters, with typed
fields, relations, JSON columns, full-text search, and sorting.

```bash
composer require hosmelq/laravel-search-syntax-parser

php artisan search-syntax-parser:install
```

Read the [full documentation](https://hosmelq.com/docs/laravel-search-syntax-parser).

## Development

Run the test suite with:

```bash
composer test
```
